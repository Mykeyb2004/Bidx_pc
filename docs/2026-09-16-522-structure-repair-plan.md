# 5.2.2 正文结构修复记录

确认范围：恢复各层级标题、标题与正文、表名与表头的换行；恢复 Mermaid 代码块独立分段、声明与首条语句分行，并拆开 `G --> F F --> I` 这类以空格粘连的完整连线。支持四层序号标题、正文和多个 Mermaid 图示全部混在同一行。`G --> FF --> I` 不拆分。自解释、自评论、自引用限制仍只通过 system 门禁约束。

## 诊断

附件与 trace `20260916_205515__5.2.2_志愿服务力量摸排__f8386f66fcb5` 的原始正文一致，共 5,423 字符。最初的编号解析器识别到 0 个标题；粘连的 Mermaid 开围栏未被识别，闭围栏又被当成开围栏，导致图后标题也被屏蔽。前一次 trace `7094a509644e` 存在同类问题，并有短冒号引导句贴着标题。

上一版已恢复图外标题与表格边界，并保护 Mermaid 全部原文。本次按进一步确认的范围增加 Mermaid 换行恢复，仍不改节点、标签或连接关系。流式接收代码在既有模拟中未丢失纯换行片段；原始日志不能区分模型输出错误与上游接口处理错误。

## 实现

`原文 → 本地恢复 Mermaid 边界 → 本地恢复标题与表格边界 → 必要时一次标题边界及层级判断 → 编号修复 → 复核 → 保存`

- `mermaid_layout.py` 只向已闭合的 Mermaid 区域插入换行：分离图名或正文与代码块、语言标记与声明、flowchart/graph 方向与首条语句、代码与闭围栏、闭围栏与后续标题或正文。
- 对完整的简单节点连线，识别 `G --> F F --> I` 中两个节点标识之间的空白并插入换行。原空格保留，节点、箭头与所有非换行字符不变；`FF` 仍为单个标识。节点标签、跨行标签、引号、注释、其他代码块、引用、表格和不确定语句不拆改。
- `body_layout.py` 在图示独立后处理各层级标题之间、加粗正式标题与正文、表名与合法表头的粘连。明确的下级标题接上级标题也能分行；“对应二、三项”等引用不据此制造标题。
- 无法本地确定的标题与正文边界仍只请求一次当前模型，选择原行精确前缀与层级；程序插入换行并重映射行号。代码块不提供给模型编辑。无效字段、遗漏、重复、错序、改写前缀及非法层级均拒绝。
- 不执行 Mermaid 渲染或完整语法校验；不猜测缺失的闭围栏。不增加配置项、模型请求预算或文风代码检核。修复后的图内称谓仍不参与主体名称替换。
- 原稿持续保留在 trace；编辑记录按 `mermaid_layout`、`layout_local`、`layout_model`、`numbering` 分阶段回放。任何后续失败均不应用局部编辑、不覆盖正式章节。GUI 与批量流程继续共用生成收尾入口。
- system 门禁同步要求图示独立成段，围栏、图声明和独立语句分别成行，不与各层级标题或正文粘连。
