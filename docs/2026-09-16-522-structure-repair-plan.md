## 实现

`原文 → 本地恢复图外边界 → 必要时一次边界及层级判断 → 编号修复 → 复核 → 保存`

- `body_layout.py` 本地分开具有明确序号关系的相邻正式标题、带明确加粗边界的正式标题与正文、表名与合法表头。表格要求下一行有列数一致的分隔行。
- 对无法本地确定的标题与正文边界，模型仅选择原行精确前缀和层级。程序插入换行并映射后续行号，不接受改写内容。长冒号引导句也会进入候选判断，模型可以确认其完整标题身份而保留原行。
- 普通枚举可通过 `level=null,prefix=null` 保留，不凭空制造标题；纯正文没有编号线索时不发起修复请求。
- 边界与层级判断合用一次模型请求预算，SDK 不重试，保留取消和超时机制。无效字段、遗漏/重复/错序行号、不匹配前缀及非法层级均拒绝。
- Mermaid 作为不可编辑区域。扫描器识别“短图名＋粘连开围栏”至独立闭围栏，仅用于跳过代码并继续检查图后正文；图名、围栏、语言标记、声明、节点、连线及 `G --> FF --> I` 均保留原样，称谓替换也跳过代码。
- 不校验或修复 Mermaid 语法。真正缺少闭围栏时区域边界不确定，保留原稿，不补写围栏。
- 原始正文持续保留在 trace；已接受的编辑按本地断行、模型断行、编号三个阶段记录坐标。失败不应用局部候选，不覆盖正式章节。GUI 与批量流程继续使用共享生成收尾入口。
- system 门禁补充相邻标题独立成行、表名与表头分行要求。不新增配置项或文风代码检核。
